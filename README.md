# MechNode Releases

This repository holds only the **installers and the update manifest (`latest.json`)** of the MechNode desktop app. The source code is not here.

한 줄 요약: MechNode 설치본과 업데이트 매니페스트만 담는 저장소입니다. 소스 없음.

## Install

1. Open the [Releases](https://github.com/sckim-ai/MechNode-releases/releases) page.
2. Download the latest `*-setup.exe` and run it.

## Updates

From version 0.2.0 the app updates itself: it reads `latest.json` from this repository, shows an update badge in the header, and installs the new version after confirmation.
